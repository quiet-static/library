CameraPoseDirector QuietStatic.Toolkit.CameraTools.CameraPoseDirector
public class CameraPoseDirector : MonoBehaviour

Runtime/Cameras/CameraPoseDirector.cs, line 18 · Permalink

Moves a camera transform between predefined camera poses.

Remarks This component is useful for cutscenes, static camera transitions, inspection views, jumpscare setups, or any moment where the active camera needs to snap or smoothly move to a specific transform in the scene. A camera pose is represented by a normal Transform. The target camera will copy that transform's world position and world rotation either instantly through CutTo or over time through MoveTo.

public void CutTo(Transform pose)

Source, line 64 · Permalink

Instantly snaps the controlled camera to the supplied pose.

pose The transform whose world position and world rotation should be copied by the camera.

Remarks Use this for hard camera cuts, such as switching to a new cutscene angle immediately. If either the controlled camera or the supplied pose is missing, the method safely does nothing.

public void MoveTo(Transform pose)

Source, line 85 · Permalink

Smoothly moves the controlled camera to the supplied pose over moveDuration seconds.

pose The transform whose world position and world rotation should become the camera's final pose.

Remarks If another move is already in progress, it is stopped before the new move begins. This prevents overlapping camera movement coroutines from competing for control. If either the controlled camera or the supplied pose is missing, the method safely does nothing.
