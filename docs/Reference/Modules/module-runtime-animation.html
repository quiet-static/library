Usage example

Add LightFlicker to a GameObject with a Light. Wire an interaction's UnityEvent to LightFlicker.StartFlickering, and a second event to StopFlickering to restore the original light state. See LightFlicker.cs, lines 137–165.

Environment animation

  • LightFlicker varies light intensity with configurable timing.
  • Rotator continuously rotates a transform.
  • SkyboxRotation rotates the active skybox material.

Animation

Animation modules contain reusable visual motion that is not tied to character gameplay. See the nested Environment folder for rotating props, skyboxes, and flickering lights.

LightFlicker QuietStatic.Toolkit.Animation.Environment.LightFlicker
public class LightFlicker : MonoBehaviour

Runtime/Animation/Environment/LightFlicker.cs, line 20 · Permalink

Creates an atmospheric, randomized flickering effect for a Unity Light.

Remarks This component is intended for horror/environmental lighting effects such as failing fluorescent lights, unstable emergency lights, haunted hallways, or other props that should occasionally dim or blink out. The flicker loop waits a random amount of time, performs one short flicker, then restores the light back to its previous enabled/intensity state. A Light component is required on the same GameObject, but a different light can also be assigned manually through targetLight.

public void StartFlickering()

Source, line 137 · Permalink

Starts the randomized flickering loop.

Remarks Calling this method while the loop is already running has no effect. This makes it safe for other scripts, UnityEvents, or trigger volumes to call this method repeatedly without creating duplicate coroutines.

public void StopFlickering()

Source, line 155 · Permalink

Stops the randomized flickering loop and restores the light to its normal state.

Remarks This method is safe to call even when the light is not currently flickering. It always attempts to restore the light afterward.

Rotator QuietStatic.Toolkit.Animation.Environment.Rotator
public class Rotator : MonoBehaviour

Runtime/Animation/Environment/Rotator.cs, line 15 · Permalink

Continuously rotates this GameObject every frame.

Remarks This component is useful for simple ambient animation such as spinning pickups, rotating props, fan blades, warning lights, puzzle objects, or decorative scene elements. The rotation speed is stored as degrees per second for each local axis. For example, a value of (0, 90, 0) rotates the object 90 degrees per second around its Y axis.

SkyboxRotation QuietStatic.Toolkit.Animation.Environment.SkyboxRotation
public class SkyboxRotation : MonoBehaviour

Runtime/Animation/Environment/SkyboxRotation.cs, line 16 · Permalink

Continuously rotates the active scene skybox over time. This component is useful for creating subtle environmental movement, such as drifting clouds, shifting skies, dreamlike backgrounds, or other atmospheric effects where the skybox should feel alive rather than static. Requirements: - The active skybox material must support the "_Rotation" shader property. - Most built-in Unity skybox shaders include this property, but custom shaders may not.
