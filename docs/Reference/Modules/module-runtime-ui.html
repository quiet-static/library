Usage example

Example for GameQuitter.

Menu

GameQuitter exposes a UnityEvent-friendly quit action. In the Editor it stops Play Mode; in a player build it requests application exit.

Wire a button's On Click event to GameQuitter.QuitGame.

TitleMenu.prefab provides Start Game, Settings, and Exit Game navigation. Connect TitleMenuView.StartRequested to the containing game's scene-flow handler. The prefab uses a full-screen, presentation-neutral layout so games can replace colors, fonts, backgrounds, and spacing through prefab variants without changing navigation code.

PauseMenu.prefab provides Resume, Save Game, Settings, and Exit Game navigation. It is designed to be loaded as the additive pause UI scene managed by PauseManager, or placed under an existing pause Canvas. Its nested settings page uses the same persistent SettingsManager as the standalone SettingsMenu.prefab.

Assign the host game's SaveRequestChannel to PauseMenuView and its persistent SaveManager. Save Game replaces slot 0 by default (configurable in the Inspector) without resuming gameplay. The button label reports success, failure, or a missing save service. It uses the existing save format: active scene, progression flags, and registered save participants. An optional arrival spawn can be configured; an empty value uses normal scene entry on load, not the player's exact position.

All supplied menu labels use TextMeshPro. Host scenes should contain an EventSystem with InputSystemUIInputModule; the package does not require StandaloneInputModule.

UI

UI components cover HUD visibility, cursor policy, dialogue/interaction prefabs, credits, and simple menu helpers.

UI
├── UIControllers
├── dialogue_ui
├── interaction_ui
└── hud

Keep the UI scene persistent when transitions should preserve it. Let UI listen to manager events; avoid making gameplay objects search the canvas hierarchy.

Menu button audio

The starter title, pause, settings, and rebind prefabs use AudibleButton for menu actions. Add one ButtonAudioFeedback to the persistent audio scene and assign its click clip and output mixer group. The component plays the clip when an active, interactable AudibleButton receives a left click or a UI submit, including while listener audio is paused. Use AudibleButton for custom menu actions that should share this feedback.

Shared progress-bar styling

ProgressBarTheme is a reusable ScriptableObject shared by world-space and screen-space meters. WorldSpaceProgressBar applies it directly, while ScreenSpaceProgressBarStyle adapts the same theme to a standard UI Slider. This keeps screen-space interaction meters visually consistent with world-space meters without changing where either one is rendered.
