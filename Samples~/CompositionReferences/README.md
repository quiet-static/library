# Composition References (Non-Runnable)

These scenes are intentionally diagram-like references for inspecting component and
prefab composition. They are not part of the executable sample, are not added to Build
Settings by the sample setup command, and may retain optional presentation fields that
must be supplied by a consuming project.

- `PrefabCompositionReference` groups representative audio, environment,
  interaction, and player prefabs.
- `NarrativeAndHorrorCompositionReference` shows story-sequence and tension-controller
  placement alongside reusable definition assets in `Data`.

Copy the relevant pattern into project-owned content and assign the channels, media,
and presentation assets required by that project. For a runnable starting point, import
**Executable Toolkit Example** instead.
