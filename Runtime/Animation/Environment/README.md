# Environment animation

- `LightFlicker` varies light intensity with configurable timing.
- `Rotator` continuously rotates a transform.
- `SkyboxRotation` rotates the active skybox material.

```text
Flickering Lamp
├── Light
└── LightFlicker
```

Use the included prefabs for safe defaults. Duplicate materials before animating shared
skybox properties when different scenes need independent settings.
